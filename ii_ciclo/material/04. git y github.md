# Git y GitHub (Guía de Instalación y Uso)

---

# 1. Crear una cuenta de GitHub

GitHub es la plataforma donde se almacenan y comparten los repositorios.

## Paso 1

Ingrese a:

```text
https://github.com/
```

Seleccione **Sign up** y cree una cuenta.

## Paso 2

Complete el registro utilizando:

* Correo electrónico.
* Contraseña.
* Nombre de usuario.

Utilice un nombre de usuario formal y fácil de reconocer, ya que forma parte de la dirección de los repositorios que cree. 

## Paso 3

Verifique el correo electrónico enviado por GitHub.

Una vez verificado, ingrese nuevamente a:

```text
https://github.com/
```

y compruebe que puede acceder a su perfil.

---

# 2. Instalar Git

Git es el programa que permite llevar el control de versiones de los proyectos.

## Paso 1

Descargue Git desde el sitio oficial:

```text
https://git-scm.com/install/
```

## Paso 2

Ejecute el instalador.

Durante la instalación puede mantener las opciones predeterminadas.

## Paso 3

Una vez finalizada la instalación, abra una terminal:

* PowerShell
* Símbolo del sistema
* Git Bash

y ejecute:

```bash
git --version
```

Debe aparecer una versión de Git.

Por ejemplo:

```text
git version 2.55.0
```

La versión exacta puede ser diferente.

---

# 3. Instalar Visual Studio Code

Abra Visual Studio Code.

Para utilizar las funciones de control de versiones, VS Code utiliza la instalación de Git disponible en la computadora.

---

# 4. Iniciar sesión en GitHub desde VS Code

En VS Code, abra la vista de control de código fuente.

También puede utilizar:

```text
Ctrl + Shift + G
```

Cuando VS Code necesite autenticarse con GitHub, aparecerá la opción correspondiente para iniciar sesión.

Siga el proceso de autenticación en el navegador y regrese a VS Code.

---

# 5. Configurar el nombre y correo de Git

Git utiliza un nombre y un correo electrónico para identificar los commits.

Abra una terminal en VS Code:

```text
Terminal → New Terminal
```

Ejecute:

```bash
git config --global user.name "Su Usuario"
```

Ejemplo:

```bash
git config --global user.name "LSBR29"
```

Después configure el correo:

```bash
git config --global user.email "santiagobrenesruiz@gmail.com"
```

Utilice el correo que corresponda a su cuenta de GitHub.

Para comprobar la configuración:

```bash
git config --global user.name
git config --global user.email
```

---

# 6. Crear un repositorio desde GitHub

El repositorio se creará desde la página de GitHub.

## Paso 1

Ingrese a:

```text
https://github.com/
```

Inicie sesión.

## Paso 2

Seleccione:

```text
New repository
```

## Paso 3

Configure el repositorio.

Por ejemplo:

```text
Repository name:
primer-proyecto-github
```

Puede seleccionar:

```text
Public
```

Active:

```text
Add a README file
```

De esta manera GitHub creará automáticamente el primer archivo del proyecto.

Finalmente, seleccione:

```text
Create repository
```

---

# 7. Copiar la dirección del repositorio

Una vez creado el repositorio, abra:

```text
Code
```

y seleccione la opción:

```text
HTTPS
```

Copie la dirección mostrada.

Tendrá una estructura similar a:

```text
https://github.com/usuario/primer-proyecto-github.git
```

La dirección será diferente para cada repositorio.

---

# 8. Clonar el repositorio en la computadora

En VS Code:

```text
Ctrl + Shift + P
```

Busque:

```text
Git: Clone
```

Seleccione:

```text
Git: Clone
```

Pegue la dirección del repositorio copiada anteriormente.

VS Code solicitará una carpeta donde guardar el proyecto.

Después de clonar el repositorio, VS Code ofrecerá abrirlo.

Seleccione:

```text
Open
```

---

# 9. Comprobar que el repositorio está conectado

Al abrir la carpeta en VS Code, podrá ver:

```text
README.md
```

También aparecerá la opción **Source Control** en la barra lateral.

Utilice:

```text
Ctrl + Shift + G
```

para abrirla.

---

# 10. Crear un archivo de C++

Dentro del repositorio cree:

```text
main.cpp
```

Utilice inicialmente:

```cpp
#include <iostream>

using namespace std;

int main() {
    cout << "Mi primer repo con GitHub" << endl;

    return 0;
}
```

Guarde el archivo.

En la sección **Source Control** aparecerá:

```text
main.cpp
```

como archivo nuevo.

---

# 11. Crear el primer commit

En la sección **Source Control**, escriba como mensaje:

```text
Proyecto inicial
```

Después seleccione:

```text
Commit
```

El commit registra ese estado del proyecto en el historial de Git.

---

# 12. Subir el commit a GitHub

Después del commit, utilice la opción:

```text
Sync Changes
```

o:

```text
Push
```

Esto enviará los cambios de la computadora al repositorio de GitHub.

Regrese a la página del repositorio en GitHub y actualícela.

Ahora debería aparecer:

```text
README.md
main.cpp
```

---

# 13. Editar el README directamente desde GitHub

Ahora realizaremos una modificación sin utilizar VS Code.

Ingrese al repositorio desde la página de GitHub.

Abra:

```text
README.md
```

Seleccione:

```text
Edit
```

o el ícono de lápiz.

Agregue, por ejemplo:

```markdown
# Mi primer proyecto con GitHub

Este es mi primer repositorio utilizando Git, GitHub y Visual Studio Code.

## Contenido

- Programa en C++.
- Control de versiones.
- Primeros commits.
```

Cuando termine, seleccione:

```text
Commit changes
```

Utilice un mensaje como:

```text
Se actualizo el README
```

Confirme el cambio.

---

# 16. Obtener los cambios desde GitHub

Regrese a VS Code.

En la sección **Source Control**, utilice:

```text
Pull
```

o:

```text
Sync Changes
```

Esto permitirá obtener los cambios realizados directamente en GitHub.

Después de actualizar el repositorio local, abra:

```text
README.md
```

y compruebe que contiene la modificación realizada desde GitHub.
