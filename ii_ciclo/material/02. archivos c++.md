# Archivos en C++

Durante la ejecución de un programa, los datos pueden almacenarse en variables, estructuras y contenedores como `vector`. Sin embargo, estos datos se encuentran en la memoria del programa y se pierden cuando finaliza la ejecución.

Los archivos permiten conservar información para utilizarla posteriormente.

---

## Archivos de texto

Un archivo de texto almacena información utilizando caracteres.

Por ejemplo, un archivo llamado `datos.txt` puede contener:

```text
Hola mundo
C++ puede trabajar con archivos
Este es un archivo de texto
```

El contenido puede ser leído directamente por una persona.

En C++, la información almacenada en un archivo de texto se procesa inicialmente como texto.

Por ejemplo:

```text
101,Interestelar,Ciencia Ficcion,169,9.5
```

Para el programa, inicialmente esto es una secuencia de caracteres.

El programa debe interpretar qué representa cada parte.

---

## Archivos CSV

CSV significa **Comma-Separated Values**.

Es un formato de texto utilizado para almacenar información organizada en filas y columnas.

Los campos normalmente se separan utilizando una coma:

```text
101,Interestelar,Ciencia Ficcion,169,9.5
102,Coco,Animacion,105,8.8
103,Matrix,Ciencia Ficcion,136,8.7
```

Cada línea representa un registro.

```text
101,Interestelar,Ciencia Ficcion,169,9.5
│   │            │               │   │
│   │            │               │   └── Calificación
│   │            │               └────── Duración
│   │            └────────────────────── Género
│   └─────────────────────────────────── Nombre
└─────────────────────────────────────── Código
```

Los datos siguen siendo texto hasta que el programa los procesa y convierte.

# `<fstream>`

La biblioteca `<fstream>` contiene las herramientas necesarias para trabajar con archivos.

```cpp
#include <fstream>
```

Las principales clases son:

| Clase      | Uso                      |
| ---------- | ------------------------ |
| `ofstream` | Escribir archivos        |
| `ifstream` | Leer archivos            |
| `fstream`  | Leer y escribir archivos |

---

## `ofstream`

`ofstream` permite escribir información en un archivo.

### Ejemplo

```cpp
#include <iostream>
#include <fstream>

using namespace std;

int main() {

    ofstream archivo("datos.txt");

    archivo << "Hola mundo" << endl;
    archivo << "C++ puede escribir archivos" << endl;

    archivo.close();

    return 0;
}
```

Después de ejecutar el programa se crea:

```text
datos.txt
```

con el contenido:

```text
Hola mundo
C++ puede escribir archivos
```

---

## Crear un archivo

Un archivo puede abrirse al crear el objeto `ofstream`.

```cpp
ofstream archivo("datos.txt");
```

El nombre del archivo se encuentra entre comillas.

```cpp
ofstream archivo("datos.txt");
```

Si el archivo no existe, se crea.

---

## Escribir en un archivo

El operador `<<` utilizado con `cout` también puede utilizarse con un archivo.

```cpp
archivo << "Hola mundo" << endl;
```

También pueden escribirse variables:

```cpp
string nombre = "Luis";

archivo << nombre << endl;
```

O varios datos:

```cpp
int edad = 20;
double nota = 9.5;

archivo << edad << " " << nota << endl;
```

---

## Cerrar un archivo

Cuando se termina de trabajar con el archivo se puede utilizar:

```cpp
archivo.close();
```

La estructura básica es:

```cpp
ofstream archivo("datos.txt");

archivo << "Contenido";

archivo.close();
```

---

## Verificar si el archivo pudo abrirse

La apertura de un archivo puede fallar.

Por ejemplo:

```cpp
ofstream archivo("datos.txt");

if (!archivo) {
    cout << "No se pudo abrir el archivo." << endl;
}
```

También puede utilizarse `is_open()`:

```cpp
ofstream archivo("datos.txt");

if (archivo.is_open()) {
    cout << "Archivo abierto correctamente." << endl;
}
```

---

## `open()`

El archivo también puede abrirse después de crear el objeto.

```cpp
ofstream archivo;

archivo.open("datos.txt");

archivo << "Hola mundo";

archivo.close();
```

La operación de apertura también puede realizarse con `ifstream`.

```cpp
ifstream archivo;

archivo.open("datos.txt");
```

---

## `ios::app`

Al escribir en un archivo, puede ser necesario conservar el contenido existente y agregar nueva información al final.

Para esto se utiliza:

```cpp
ios::app
```

### Ejemplo

```cpp
ofstream archivo("datos.txt", ios::app);

archivo << "Nueva linea" << endl;

archivo.close();
```

El contenido existente se mantiene y la nueva información se agrega al final.

```text
Contenido anterior

Nueva linea
```

---

## Modos de apertura

Al abrir un archivo se pueden utilizar diferentes modos.

| Modo          | Descripción                     |
| ------------- | ------------------------------- |
| `ios::in`     | Abrir para lectura              |
| `ios::out`    | Abrir para escritura            |
| `ios::app`    | Escribir al final               |
| `ios::trunc`  | Eliminar el contenido existente |
| `ios::binary` | Trabajar en modo binario        |

Ejemplo:

```cpp
ofstream archivo("datos.txt", ios::app);
```

# `ifstream`

`ifstream` permite leer información desde un archivo.

### Ejemplo

```cpp
#include <iostream>
#include <fstream>

using namespace std;

int main() {

    ifstream archivo("datos.txt");

    string linea;

    while (getline(archivo, linea)) {
        cout << linea << endl;
    }

    archivo.close();

    return 0;
}
```

Si `datos.txt` contiene:

```text
Hola mundo
C++ puede escribir archivos
```

la salida será:

```text
Hola mundo
C++ puede escribir archivos
```

---

## Leer un archivo línea por línea

La función `getline()` permite obtener una línea completa.

```cpp
string linea;

while (getline(archivo, linea)) {
    cout << linea << endl;
}
```

El proceso se repite hasta llegar al final del archivo.

---

# `getline()` con delimitadores

`getline()` también puede utilizar un delimitador.

La sintaxis es:

```cpp
getline(flujo, variable, delimitador);
```

Por ejemplo:

```cpp
getline(ss, nombre, ',');
```

lee información hasta encontrar una coma.

El delimitador no se almacena en la variable.

---

# `stringstream`

`stringstream` permite trabajar con un `string` como un flujo.

Se encuentra en:

```cpp
#include <sstream>
```

### Ejemplo

```cpp
string texto = "101 Interestelar";

stringstream ss(texto);

int codigo;
string nombre;

ss >> codigo;
ss >> nombre;
```

Después:

```text
codigo : "101"
nombre : "Interestelar"
```

---

## Procesar texto separado por comas

`stringstream` resulta especialmente útil para procesar información CSV.

Supongamos:

```cpp
string linea = "101,Interestelar,Ciencia Ficcion";
```

Se puede separar de la siguiente forma:

```cpp
stringstream ss(linea);

string codigo;
string nombre;
string genero;

getline(ss, codigo, ',');
getline(ss, nombre, ',');
getline(ss, genero, ',');
```

Resultado:

```text
codigo : "101"
nombre : "Interestelar"
genero : "Ciencia Ficcion"
```

---

# Procesar un registro CSV

Supongamos que tenemos:

```text
101,Interestelar,Ciencia Ficcion,169,9.5
```

Primero se almacena la línea:

```cpp
string linea = "101,Interestelar,Ciencia Ficcion,169,9.5";
```

Después se crea el `stringstream`:

```cpp
stringstream ss(linea);
```

Se separan los campos:

```cpp
string codigo;
string nombre;
string genero;
string duracion;
string calificacion;

getline(ss, codigo, ',');
getline(ss, nombre, ',');
getline(ss, genero, ',');
getline(ss, duracion, ',');
getline(ss, calificacion, ',');
```

Ahora:

```text
codigo       : "101"
nombre       : "Interestelar"
genero       : "Ciencia Ficcion"
duracion     : "169"
calificacion : "9.5"
```

Todos los valores todavía son `string`.

# `stoi()`

`stoi()` convierte un `string` en un `int`.

```cpp
string texto = "169";

int duracion = stoi(texto);
```

Antes:

```text
"169"
```

Después:

```text
169
```

### Ejemplo

```cpp
string texto = "100";

int numero = stoi(texto);

cout << numero + 50 << endl;
```

Salida:

```text
150
```

---

# `stod()`

`stod()` convierte un `string` en un `double`.

```cpp
string texto = "9.5";

double calificacion = stod(texto);
```

Antes:

```text
"9.5"
```

Después:

```text
9.5
```

### Ejemplo

```cpp
string texto = "9.5";

double numero = stod(texto);

cout << numero + 0.5 << endl;
```

Salida:

```text
10
```

---

# Procesar y convertir un CSV

Los campos obtenidos del archivo pueden convertirse a sus tipos correspondientes.

```cpp
string linea = "101,Interestelar,Ciencia Ficcion,169,9.5";

stringstream ss(linea);

string codigoTexto;
string nombre;
string genero;
string duracionTexto;
string calificacionTexto;

getline(ss, codigoTexto, ',');
getline(ss, nombre, ',');
getline(ss, genero, ',');
getline(ss, duracionTexto, ',');
getline(ss, calificacionTexto, ',');

int codigo = stoi(codigoTexto);
int duracion = stoi(duracionTexto);
double calificacion = stod(calificacionTexto);
```

Resultado:

```text
codigo       : 101
nombre       : Interestelar
genero       : Ciencia Ficcion
duracion     : 169
calificacion : 9.5
```

# Escribir información del `vector`

También se puede utilizar un `vector` como fuente de información para escribir un archivo.

```cpp
ofstream archivo("resultados.txt");

for (int i = 0; i < peliculas.size(); i++) {
    archivo << peliculas[i].nombre << endl;
}

archivo.close();
```

---

# `fstream`

`fstream` permite realizar operaciones de lectura y escritura.

```cpp
#include <fstream>

fstream archivo;
```

Por ejemplo:

```cpp
fstream archivo("datos.txt");
```

Sin embargo, cuando solamente se necesita leer o escribir, normalmente resulta más claro utilizar:

```cpp
ifstream
```

o:

```cpp
ofstream
```
