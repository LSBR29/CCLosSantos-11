# Estructuras de Datos y Rendimiento

> **Si el problema ya se sabe resolver en Python, ¿qué cambia al resolverlo en C++?**

---

## Un mismo problema en dos lenguajes

**Problema:** contar cuántas veces aparece cada producto en una lista de ventas.

### Python

```python
ventas = ["Teclado", "Mouse", "Mouse", "Monitor", "Teclado", "Mouse"]

conteo = {}
for producto in ventas:
    if producto not in conteo:
        conteo[producto] = 0
    conteo[producto] += 1
```

### C++

```cpp
#include <iostream>
#include <map>
#include <vector>
#include <string>

using namespace std;

int main() {
    vector<string> ventas = {"Teclado", "Mouse", "Mouse", "Monitor", "Teclado", "Mouse"};

    map<string, int> conteo;

    for (int i = 0; i < ventas.size(); i++) {
        conteo[ventas[i]]++;
    }

    return 0;
}
```

No hace falta comprobar si la clave existe antes de incrementarla: si `conteo[ventas[i]]` no existe todavía, `map` la crea automáticamente con el valor por defecto del tipo (`0` para `int`) y luego aplica `++`. Ese es un comportamiento propio de `map` que no tiene equivalente directo en `dict`.

---

## `dict` frente a `map`

| Concepto                     | Python (`dict`)              | C++ (`map`)                          |
| ----------------------------- | ----------------------------- | -------------------------------------- |
| Declaración                   | `conteo = {}`                 | `map<string, int> conteo;`             |
| Tipo de clave y valor         | dinámico, cualquier tipo      | fijo, se declara con `< >`             |
| Acceso                        | `conteo["Mouse"]`             | `conteo["Mouse"]`                      |
| Clave que no existe (lectura) | `KeyError`                    | se crea con valor por defecto          |
| Orden de las claves           | orden de inserción            | orden ascendente automático de la clave |
| Verificar existencia          | `"Mouse" in conteo`           | `conteo.count("Mouse")` o `conteo.find("Mouse")` |
| Bibliotecas requeridas        | ninguna                       | `#include <map>`                       |

Para solo consultar sin crear una entrada nueva:

```cpp
if (conteo.find("Mouse") != conteo.end()) {
    cout << conteo["Mouse"];
}
```

### Recorrer un `map`

```cpp
for (auto par : conteo) {
    cout << par.first << ": " << par.second << endl;
}
```

`par.first` es la clave y `par.second` es el valor. Equivale a:

```python
for clave, valor in conteo.items():
    print(clave, valor)
```

## `set` en C++

Un `set` almacena elementos únicos, sin duplicados, igual que en Python. Requiere `#include <set>`.

### Python

```python
productos = set()
productos.add("Mouse")
productos.add("Mouse")   # no se duplica
```

### C++

```cpp
#include <set>

set<string> productos;
productos.insert("Mouse");
productos.insert("Mouse");   // no se duplica

cout << productos.size();    // 1
```

| Operación         | Python           | C++                  |
| ----------------- | ---------------- | --------------------- |
| Crear             | `set()`          | `set<string> s;`      |
| Agregar           | `s.add(x)`       | `s.insert(x);`        |
| Cantidad          | `len(s)`         | `s.size()`            |
| Verificar         | `x in s`         | `s.count(x)` o `s.find(x)` |
| Eliminar          | `s.remove(x)`    | `s.erase(x);`         |

A diferencia de un `vector`, un `set` en C++ mantiene sus elementos ordenados automáticamente y no permite acceso por índice (`s[0]` no existe).

### Equivalencias generales

| Python  | C++      |
| ------- | -------- |
| `list`  | `vector` |
| `dict`  | `map`    |
| `set`   | `set`    |

## Copias y referencias

Python y C++ manejan la asignación de variables de forma distinta cuando se trata de estructuras compuestas.

### Python

```python
pelicula = {"nombre": "Interestelar", "calificacion": 8.7}
otra = pelicula
otra["calificacion"] = 9.0

print(pelicula["calificacion"])   # 9.0
```

`pelicula` y `otra` apuntan al mismo diccionario. Modificar uno modifica el otro.

### C++

```cpp
struct Pelicula {
    string nombre;
    double calificacion;
};

Pelicula pelicula;
pelicula.nombre = "Interestelar";
pelicula.calificacion = 8.7;

Pelicula otra = pelicula;   // copia completa e independiente
otra.calificacion = 9.0;

cout << pelicula.calificacion;   // 8.7, no cambia
```

En C++, `otra = pelicula` crea una copia nueva con los mismos valores. Cambiar `otra` no afecta a `pelicula`.

Para obtener el mismo comportamiento que en Python (que ambos nombres se refieran al mismo objeto), se usa una referencia con `&`:

```cpp
Pelicula& otra = pelicula;
otra.calificacion = 9.0;

cout << pelicula.calificacion;   // 9.0, sí cambia
```

| Comportamiento                          | Python (objetos compuestos) | C++ (`=` sobre `struct`) | C++ (`&`) |
| ---------------------------------------- | ---------------------------- | ------------------------- | --------- |
| Copia independiente                      | no                            | sí                        | no        |
| Cambios se reflejan en el original        | sí                            | no                        | sí        |

## Paso de parámetros: por valor y por referencia

La misma distinción aplica al pasar datos a una función.

### Por valor (copia)

```cpp
void modificar(Pelicula pelicula) {
    pelicula.calificacion = 10;   // solo cambia la copia local
}
```

Al llamar `modificar(pelicula)`, la función recibe una copia. El objeto original queda igual.

### Por referencia

```cpp
void modificar(Pelicula& pelicula) {
    pelicula.calificacion = 10;   // cambia el objeto original
}
```

Con `&`, la función trabaja directamente sobre la variable pasada como argumento.

En Python no existe esta distinción explícita: los argumentos siempre se pasan como referencias al objeto. Por eso mutar un objeto dentro de una función (`lista.append(x)`, `diccionario[clave] = valor`) sí se refleja afuera.

## `const`: leer sin copiar y sin modificar

Cuando una función solo necesita **leer** un objeto, copiarlo por valor es un costo innecesario, y pasarlo por referencia sin protección permite modificarlo por error. La combinación `const &` resuelve ambos problemas: evita la copia y prohíbe cualquier modificación dentro de la función.

```cpp
void mostrar(const Pelicula& pelicula) {
    cout << pelicula.nombre << endl;
    pelicula.calificacion = 10;   // error de compilación
}
```

Python no tiene un equivalente directo a `const`: cualquier parámetro puede reasignarse o, si es mutable, modificarse dentro de la función sin que el lenguaje lo impida.

| Firma de la función              | ¿Copia el objeto? | ¿Permite modificarlo? |
| ---------------------------------- | -------------------- | ------------------------ |
| `void f(Pelicula p)`               | sí                    | sí (solo la copia)       |
| `void f(Pelicula& p)`               | no                    | sí (afecta al original)  |
| `void f(const Pelicula& p)`        | no                    | no                        |

## Rendimiento: medir el tiempo de ejecución

C++ permite medir cuánto tarda un bloque de código con la biblioteca `<chrono>`.

```cpp
#include <chrono>
using namespace std::chrono;

int main() {
    auto inicio = high_resolution_clock::now();

    // bloque de código a medir

    auto fin = high_resolution_clock::now();
    auto duracion = duration_cast<milliseconds>(fin - inicio);

    cout << duracion.count() << " ms" << endl;

    return 0;
}
```

En Python, la medición equivalente se hace con el módulo `time`:

```python
import time

inicio = time.perf_counter()

# bloque de código a medir

fin = time.perf_counter()
print((fin - inicio) * 1000, "ms")
```

No es necesario memorizar la sintaxis de `chrono`; lo que importa es poder comparar el tiempo que toma resolver el mismo problema con distintas estructuras de datos.

## Elegir la estructura correcta: `vector`, `set` y `map`

Cada estructura tiene un costo distinto según la operación que se realice. `set` y `map` en C++ mantienen sus elementos ordenados internamente, lo que permite búsquedas más rápidas que en un `vector` sin ordenar.

| Estructura | Buscar un elemento | Insertar          | Acceso por índice |
| ---------- | ------------------- | ------------------ | -------------------- |
| `vector`   | O(n)                 | O(1) al final, O(n) en medio | O(1)         |
| `set`      | O(log n)             | O(log n)            | no existe             |
| `map`      | O(log n) por clave   | O(log n)            | por clave, O(log n)   |

En un `vector` sin ordenar, buscar un elemento requiere revisarlo uno por uno (búsqueda lineal). En `set` y `map`, la búsqueda aprovecha su orden interno y no necesita recorrer todos los elementos.

Esto no significa que `set` o `map` sean siempre mejores: si solo se necesita recorrer datos en el orden en que se agregaron y acceder por posición, `vector` sigue siendo la opción más simple y directa.

## Ordenamiento con `sort`

`sort` requiere `#include <algorithm>` y recibe dos iteradores que delimitan el rango a ordenar.

```cpp
#include <algorithm>

sort(peliculas.begin(), peliculas.end());
```

Por defecto ordena usando el operador mayor que (`<`). Para ordenar por un campo específico hace falta indicarle a `sort` cómo comparar dos elementos.

### Comparador como función

```cpp
bool compararCalificacion(const Pelicula& a, const Pelicula& b) {
    return a.calificacion > b.calificacion;   // mayor calificación primero
}

sort(peliculas.begin(), peliculas.end(), compararCalificacion);
```

`compararCalificacion` debe devolver `true` si `a` debe ir antes que `b`.

### Comparador como lambda

Python ya permite pasar una función como argumento con `key=`:

```python
peliculas.sort(key=lambda p: p["calificacion"], reverse=True)
```

C++ tiene su propio equivalente a una función anónima, la **lambda**:

```cpp
sort(peliculas.begin(), peliculas.end(),
    [](const Pelicula& a, const Pelicula& b) {
        return a.calificacion > b.calificacion;
    }
);
```

No hace falta darle un nombre porque solo se usa una vez, en el lugar donde se necesita, igual que un `lambda` de Python.

| Concepto                          | Python                                   | C++                                                             |
| ------------------------------------ | ------------------------------------------ | ------------------------------------------------------------------ |
| Ordenar                              | `lista.sort()`                              | `sort(v.begin(), v.end());`                                        |
| Ordenar por un criterio              | `lista.sort(key=...)`                       | `sort(v.begin(), v.end(), comparador);`                             |
| Orden descendente                    | `reverse=True`                              | invertir la comparación dentro del comparador (`>` en vez de `<`)   |
| Función anónima                      | `lambda x: ...`                             | `[](parametros) { ... }`                                            |
